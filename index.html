常见问题 · FAQ

如何备份我的任务数据?(JSON 备份)

打开 设置 → 数据 → 导出 JSON 备份,选择保存位置即可生成包含所有清单与任务的备份文件。How to back up: Settings → Data → Export JSON Backup, then choose where to save the file containing all your lists and tasks.

如何从备份恢复数据?(JSON 恢复)

打开 设置 → 数据 → 从 JSON 恢复,选择之前导出的备份文件。恢复会以备份内容替换当前数据,建议先导出一份当前备份。Restore: Settings → Data → Restore from JSON and pick a previously exported backup. Restoring replaces current data, so export a fresh backup first if needed.

如何导出 CSV?Excel 打开乱码怎么办?

CSV 导出属于专业版功能:设置 → 专业版 → 导出 CSV。导出的文件带 UTF-8 BOM,可直接用 Excel、Numbers 或 Google Sheets 打开,中文不乱码。CSV export is a Pro feature: Settings → Pro → Export CSV. Files include a UTF-8 BOM and open cleanly in Excel, Numbers, or Google Sheets.

专业版(Pro)如何购买?换设备后如何找回?

专业版为一次性买断(非订阅),包含导出 CSV 与专业数据洞察。在新设备上,进入 设置 → 专业版 → 恢复购买,登录同一 Apple ID 即可免费恢复。Pro is a one-time purchase (not a subscription) that unlocks CSV export and Pro Insights. On a new device, use Settings → Pro → Restore Purchases with the same Apple ID.

提醒没有响起?

请在系统设置中允许通知:系统设置 → 通知 → Todo list专业版,并确保任务设置了提醒时间。macOS 下请确认未开启专注模式屏蔽。Enable notifications in System Settings → Notifications → Todo List Pro and make sure the task has a reminder time. Also check that a Focus mode isn't silencing notifications.

我的数据会上传到服务器吗?

不会。所有任务数据仅保存在你的设备本地,应用没有账号系统、没有云端存储、不收集任何个人数据。备份与导出完全由你掌控。No. All tasks are stored locally on your device only. There is no account system, no cloud storage, and no personal data collection. Backups and exports stay fully under your control.

支持哪些设备与系统?

iPhone、iPad、Mac(含菜单栏快速添加)与小组件,数据在每台设备本地独立保存。Supported on iPhone, iPad, and Mac (with a menu bar quick-add), plus widgets. Data is stored locally per device.
